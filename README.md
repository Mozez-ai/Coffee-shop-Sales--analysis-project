# ☕ Coffee Shop Sales Analysis (2023)

Welcome to my data analysis project! This project dives deep into one year of sales data from a fictional coffee shop, using **SQL** and **Power BI** to uncover trends, insights, and opportunities for growth.

## 📊 Project Overview

The goal of this project was to analyze sales data from the year **2023** and answer key business questions like:

- What were the best-selling products?
- Which months had the highest and lowest sales?
- Who were the top-performing branches?
- What are customer buying patterns over the year?

## 🛠️ Tools Used

- **SQL** — for cleaning, filtering, and querying the raw sales data
- **Power BI** — for creating interactive dashboards and data visualizations

## 📈 Key Insights

- Seasonal sales trends and peak months
- Top-selling coffee and pastry items
- Branch performance comparisons
- Opportunities to boost slow months

## 🎯 What I Learned

- Writing efficient SQL queries to prepare and explore large datasets
- Designing clear, interactive dashboards with Power BI
- Turning raw data into real business insights

## 📁 Project Files

- `.pbix` file (Power BI dashboard)
- SQL scripts used for data cleaning and exploration
